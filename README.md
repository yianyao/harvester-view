# harvester-view

会话索引库的**独立只读视图**：给人用的会话列表 / 筛选 / 逐回合下钻页面。
零构建、零第三方依赖（Python stdlib + 原生 JS 单文件前端）。

与本套件索引服务**互不留痕、只经 HTTP 接口通信、双向只读**：
本项目不 import 任何上游代码、不知道数据库文件存在，只认识
"返回 `api_version=1` JSON 的 HTTP 服务"（下称**上游**）。

## 快速开始

```bash
# 1. 起上游（主项目侧的通用只读查询 API）
python -m harvester api-serve --db harvester.db          # 默认 127.0.0.1:8765

# 2. 起本视图（自动打开浏览器）
python view.py                                            # 默认 127.0.0.1:8088
```

无 `config.json` 时使用默认上游 `http://127.0.0.1:8765`；连不上时页面
顶部显示黄条引导，不影响其他功能。

## 页面功能

- 筛选栏：来源 / 模型 / skill / 起止日期 / 关键字（中文关键字由上游的
  bigram 全文检索保证 2 字词命中）；
- 结果表：更新时间 / 来源 / 模型 / 标题，关键字命中处 `<mark>` 高亮，
  按 `updated_at` 倒序，offset/limit 分页（每页 50）；
- 点行 → 回合列表（回合号 / 角色构成 / 用户侧预览）；
- 点回合 → 全文，按角色分色：用户（蓝）/ 助手（绿）/ 工具·思考
  （灰、等宽、超长折叠）/ 系统（橙）。

## 多上游（中台形态）

`config.json` 配多个上游即可，页面顶部下拉切换，各上游互不知晓：

```json
{
  "upstreams": [
    {"name": "本机",   "url": "http://127.0.0.1:8765", "token": ""},
    {"name": "工作站", "url": "http://192.168.1.20:8765", "token": "密钥"}
  ]
}
```

- 代理路由 `GET /u/<编号>/api/*`，编号 = `upstreams` 数组下标（0 起）；
- 上游 `token` 非空时转发自动携带 `X-Token` 头；
- `GET /u/all/facets` 聚合全部上游的 facets（按 name 计数求和），
  不可达上游跳过并在结果中标注 error（跨实例搜索属 v2）。

## 安全与版本协商

- 本服务只读：仅转发 GET，非 GET 一律 405；仅转发 `/api/*` 子路径；
  默认绑 `127.0.0.1`；
- 版本协商：上游 200 响应携带 `api_version` 且 major ≠ 1 时明确报
  "上游 API 版本过旧/过新，请升级对应侧"（不携带该字段的端点放行）；
- 上游不可达/超时 → 502 `kind=unreachable`（页面黄条 + 引导文案），
  上游 401/404/5xx 错误原样透传，页面按状态提示。
